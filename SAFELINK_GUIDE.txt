SAFELINK - JSON STORAGE VERSION

IMPORTANT:
This version DOES NOT USE:
- MySQL
- mysql.connector
- SQL
- XAMPP
- MySQL Server
- Port 3306

All application data is stored locally in:
data/safelink_data.json

RUN:
1. Open Command Prompt in this folder.
2. Run:
   pip install -r requirements.txt
3. Run:
   python run.py
4. Open:
   http://127.0.0.1:5000
